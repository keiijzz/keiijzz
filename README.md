- 🔭 Saat ini kerja sebagai **Network Engineer & IT Helpdesk** di **PT Kaldyta Mega Tech (KMTech)**, ditugasin sebagai vendor di **Universitas Nusa Putra**, Sukabumi, Jawa Barat.
- 🌐 Sehari-hari ngurusin infrastruktur jaringan kampus — MikroTik multi-WAN & VLAN, FreeRADIUS di atas Proxmox, Unbound DNS, sampe monitoring pake Prometheus & Grafana.
- 🌱 Lagi transisi karier ke arah **DevOps / Automation Engineering**, mulai dari Cloud Engineering (AWS) sebagai fondasi awal.
- 🤖 Suka banget ngoprek automation pake **Python, Docker, dan SSH scripting** buat mempermudah kerjaan infra sehari-hari.
- 📜 Pemegang sertifikasi **MTCNA (MikroTik Certified Network Associate)**.
- ✍️ Rajin nulis catatan & dokumentasi teknis di blog dan personal knowledge base.
- ⚡ Fun fact: awalnya dari dunia hands-on IT support, tapi makin ke sini makin jatuh cinta sama scripting & automation.
